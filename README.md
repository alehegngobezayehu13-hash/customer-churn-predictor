# Customer Churn Prediction

An machine learning project that predicts whether a customer is likely to leave a company.

## Features

- Data preprocessing
- Categorical encoding
- Logistic Regression model
- Model evaluation
- Interactive prediction system
- Data visualization

## Technologies Used

- Python
- pandas
- scikit-learn
- matplotlib
